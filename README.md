# tessellation.exe

## Overview

This program performs sphere tessellation using DirectX 11.

## Notes

- tessellation.exe : Executable file
- dx11.hlsl : Shader file
- PPDX11TEX : Backup folder for texture editing
- test.wrf : Sphere polygon sample
- test.jpg : Texture sample

## Supported Image Formats

- Place all of the above files in the same folder.
- Be careful when modifying dx11.hlsl, as the program may stop working.
